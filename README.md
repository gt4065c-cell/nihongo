# にほんご 75 — 일본어 일상회화 75단어·75문장 퀴즈

일본어 일상회화 핵심 75단어와 75개 암기 문장(15개 생활회화 그룹)을 문답형으로 익히는 인터랙티브 학습 사이트입니다.
한국어 / English 화면 전환을 지원합니다 (`?lang=ko`, `?lang=en`).

## 기능
- **문제 유형 6가지**: 단어→뜻, 뜻→단어, 문장→뜻, 뜻→문장, 빈칸 채우기, 듣고 고르기 (+ 모두 섞기)
- **문항별 오답 통계**: 시도 횟수 대비 틀린 횟수·오답률 — 내 기록 / 전체 학습자 기록
- **오답 복습**: 오답률 높은 문항부터 다시 출제
- **그룹별 학습**: 목록 보기, 뒤집기 카드, 일본어 음성 듣기(브라우저 TTS)
- **랭킹**: 정답 1개 = 10 XP, 친구들과 순위 경쟁
- 닉네임 기반 기록 — 같은 닉네임이면 어느 기기에서든 이어서 학습

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성과 스타일 |
| `app.js` | 퀴즈 로직, 다국어, Firebase 연동 |
| `data.js` | 75개 단어·문장 데이터 (한국어·영어 뜻, 한글 발음, 로마자) |

## Firebase Realtime Database 규칙
데이터는 `nihongo75/` 경로 아래에 저장됩니다. Firebase 콘솔 → Realtime Database → **규칙** 탭에서
기존 규칙은 그대로 두고 `"rules"` 안에 아래 블록만 추가하세요.

```json
"nihongo75": {
  ".read": true,
  ".write": true,
  "board": { ".indexOn": ["xp"] }
}
```

규칙이 막혀 있으면 사이트는 자동으로 **이 기기에만 저장** 모드로 동작합니다 (상단 닉네임 옆 점이 빨간색).
